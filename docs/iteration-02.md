# 第二轮完善记录

日期：2026-10-24。继续以代码和文档为重点，没有安装依赖、下载模型、连接 GPU 或运行训练。

## 解决的问题

| 原有缺口 | 当前处理 |
| --- | --- |
| 缺少统一的加载前检查 | preflight 汇总模型 revision、完整数据包、adapter 与恢复输入缺口；只读且不导入 GPU 库 |
| 数据只检查文件哈希 | 额外检查三份划分、context 泄漏、样本身份、token 与回答标签、声明配额 |
| 恢复仅查看 trainer_state 是否存在 | 保存文件集合与 SHA256，恢复核对优化器/调度器/RNG/adapter，绑定训练身份与 global_step |
| adapter 路径指向不同内容后仍可能混合 | 最终 adapter 自带完整性记录，E6 校验完整训练数据身份，汇总按 adapter 记录分组 |
| 日志里的吞吐等标量未复算 | 从逐步耗时复算四个统计量，数量与 token 计数不一致时拒绝引用 |
| 空行使溯源行号不准确 | 保留物理行号，静态显存直接引用 model_ready 行 |
| 所有实验共用同一审批清单 | 根据角色生成待审查草稿；E5/E6 对应检查点、数据与指标审查 |
| 执行器可能误认旧 OOM | 用唯一 job_id 关联结果并遵循配置 raw_dir；无终止证据或非 OOM 错误会停止 |
| 预算账本重复/未闭合可能错误计费 | 拒绝重复结束、负数/非有限时间、无开始的结束和未闭合任务 |

## 本轮轻量验证

新增 12 项标准库离线回归，覆盖数据泄漏、已重算文件哈希后的坏标签、缺失/损坏检查点、篡改统计量、陈旧审查失效、真实行号、旧 OOM 隔离、重复/未闭合账本等问题。运行命令：

```bash
python3 -B -m unittest discover -s tests -v
```

测试仅在系统临时目录创建带 SYNTHETIC 标记的极小样例，退出后清理。它们不写入项目 results/raw，也不代表任何模型性能；不需要 PyTorch、Transformers 或 GPU。全部 12 项通过。

当前预检会报告真实缺口：模型 revision 尚未固定，任务数据尚未准备。没有把预检失败当成环境异常，也没有为让它通过而生成假数据。
