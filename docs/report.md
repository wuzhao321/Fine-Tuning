# 实验报告结构

`summarize` 根据原始日志和审查记录生成 `results/summary/report.md`。报告包含以下内容。

## 环境

GPU 型号与精度、软件版本、镜像 digest、模型 revision、数据版本和 Git commit。

## 方法

模型构建、量化与 LoRA 设置、数据处理、注意力实现、GC、优化器、训练超参数及测量协议。

## 结果

| 实验 | 报告内容 |
| --- | --- |
| E0 | 结构检查、实际参数量与精度清单 |
| E1 | bf16 LoRA 与 QLoRA 的显存、步时和吞吐对照 |
| E2 | attention × GC 消融及 OOM 边界 |
| E3 | 序列长度扫描与扫描范围内的成功长度 |
| E4 | 优化器步时、显存及分页观测 |
| E5 | 训练/验证损失、收敛曲线与耗时 |
| E6 | 基座/微调模型的问答与摘要指标及样例 |

## 校验与局限

列出参数量、计时与 token 计数、静态显存、运算量估算、数值差异和独立重复的一致性检查。说明硬件、数据、截断、指标近似、采样频率和 profiler 覆盖范围等限制。

## 结论与引用

每个结论关联结果键、原始日志文件和物理行号。理论推导与测量结果分列，失败和中断保留在审计表。结果摘要输出为 `results/summary/result_summary.md`。
