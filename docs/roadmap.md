# 技术改进方向

## 指标与后端证据

- 将排除重算的任务 FLOPs 估算与包含重算的分析利用率分开记录，统一指标字段和汇总口径。
- 将利用率阈值作为复核条件，允许记录经解释的偏差。
- 为 SDPA 增加受控后端诊断，保存实际 kernel、Q/K/V dtype 与 attention dropout。
- 单独分析全词表 logits/loss 与模型准备过程的峰值显存。

相关原理与设计建议见 [项目研究分析](research/project-implications.md)。

## 数据与训练

- 增加选定数据集的下载和字段转换适配器。
- 在规范化完全匹配去重之外，研究近重复检测。
- 增加变长样本的 token 加权 loss 与梯度累积诊断。
- 扩展检查点恢复的模型、优化器、调度器、RNG 与数据位置一致性检查。
- 为较大语料提供流式预处理，减少全量 token 化的主机内存需求。

## 实验分析

- 结合 UVM trace 分析分页分配、预取、迁移与步时的关系。
- 增加同配置差值、GC 开销和序列长度边界分析。
- 将四投影 LoRA 与 all-linear 作为独立容量实验，并与相同目标层的 bf16 LoRA 配对。

技术扩展通过独立配置或实验编号记录，保证比较时模型、数据和工作量的可追踪性。
