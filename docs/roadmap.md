## 已知边界

当前未做 GPU 集成测试，也未生成依赖 lock，不能保证任意版本组合开箱即用。基准测量代码和分析代码实现了协议，但其正确性仍需真实环境验收。

数据去重仅覆盖规范化后的完全相同文本，不覆盖近重复；全量 token 化在内存进行，面向当前约 2 万条规模，不是大规模流式处理方案。Trainer 默认验证 loss 的聚合语义保留为库实现，不当作严格的全语料 token 加权 perplexity。

审查器验证审查字段与哈希绑定，不能代替人工核实证据内容。汇总会保留所有运行但不自动编写“FA2 提升多少”“QLoRA 更快”等跨分组因果结论。E3 最大成功长度和 GC 开销需结合 audit.csv 与失败边界在报告中解释。

原计划 B6 中的两个自建技能被落实为项目规程文档，而非另建平台专属技能。本轮未将附件内的执行 Prompt 当作要求安装软件或停止询问五项硬件信息的直接指令。
